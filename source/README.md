# source/ — matériaux bruts fournis par le client

Rien ici n'est généré. Ce dossier ne contient que ce que le client a envoyé.
C'est la base du site à construire : **aucune image ne doit être inventée.**

## photos/ — 30 photographies

Fichiers renommés depuis les noms d'origine (légendes Instagram avec émojis,
inexploitables comme noms de fichiers). La correspondance ancien ↔ nouveau nom
est conservée dans `photos-manifest.json`, index compris — l'index correspond
au numéro jaune de la planche-contact envoyée dans la conversation.

Répartition par sujet :

| Sujet | Fichiers |
|---|---|
| Train du fer | `train-fer-*` (8) |
| Ouadane / Chinguetti | `ouadane-*`, `chinguetti-ruelle`, `fort-ancien-silhouette` (6) |
| Portraits | `portrait-*`, `enfant-danse-sable`, `bibliothecaire-manuscrits` (5) |
| Désert / 4×4 | `dunes-4x4-piste*` (2) |
| Nuit / feu | `campement-feu-nuit`, `danse-feu-nuit` (2) |
| Richat | `richat-vue-aerienne` (1) |
| Terjit | `terjit-oasis`, `terjit-palmeraie` (2) |
| Manuscrits, marché, marque | `manuscrits-anciens`, `marche-artisanat`, `tshirt-horizons-*`, `equipe-tshirt-pirogue`, `vehicule-interieur-village` (5) |

⚠️ **Droits à vérifier** : les photographies du train du fer étaient créditées
`@zoefortuna` dans les noms de fichiers d'origine. Confirmer l'autorisation
d'usage commercial avant mise en ligne.

## brand/ — identité

`logo-source.jpeg` est une capture d'écran du logo (fond blanc opaque, bandes
noire et orange autour). **À remplacer par le PNG d'origine à fond transparent**
dès que le client le fournit.

Couleurs relevées sur le logo — ce sont les couleurs officielles du site :

| Rôle | Valeur |
|---|---|

| Sable chaud (dune du logo) | `#F0C078` |
| Anthracite (typographie) | `#303030` |
| Brun sombre (montagnes) | `#481818` |
